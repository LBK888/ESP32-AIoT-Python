# ESP32 + MicroPython 智慧 AIoT 魚缸
BY 國立臺灣海洋大學 水產養殖學系 廖柏凱 博士

## 前言
人工智慧物聯網（Artificial Intelligence of Things, AIoT）把感測、通訊、資料分析與自動控制結合在同一個系統中。本書以智慧魚缸為貫穿全書的實作情境，使用 ESP32 與 MicroPython，逐步完成水溫、水位、顯示、燈光、餵食、微量液體投加、控溫、水質、水色、曝氣、MQTT、TinyML 與多節點整合。
本書適合已接觸基礎 Python，或願意一邊實作一邊學習程式設計的讀者。每章包含學習目標、原理與概念、系統架構、實作流程、材料與工具、接線重點、程式核心、AI 延伸、除錯與練習。建議依章節順序進行，先在桌面或空桶完成測試，再把設備接到實際魚缸。

## 開源項目
* [microPython](/microPython) 是本課程16章的程式碼，請用Thonny將microPython安裝到ESP32內使用
* [web-app](/web-app) 是一套獨立運行的AIoT資訊面板與控制台，可以將本課程內的裝置都連線到這個中心架構
* 3D列印檔 (待新增上傳)
